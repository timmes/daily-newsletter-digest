## Top Stories

### 1. Prose as a Programming Language: How OpenProse Lets You Code in English — *Kent Beck / Software Design: Tidy First?*

Kent Beck sat down with Dan Blumenau, co-founder of OpenProse, a framework that allows you to write programs in structured English and execute them with an AI agent like Claude Code. Each component in OpenProse has a `requires` block (what it expects from its caller) and an `ensures` block (what it promises to produce — effectively a postcondition), and an inversion-of-control container wires components together by matching these blocks, the same way Spring wires Java beans, except the entire system runs in natural language via an LLM. To manage context cleanly, sub-agents pass file paths rather than raw data: when a sub-agent produces large output (a PDF analysis, a tide chart), it writes it to disk and returns the path, keeping the main agent's context window uncluttered. Blumenau's answer to the Dijkstra objection — that natural language is too ambiguous to be a programming language — is empirical rather than theoretical: "We don't know what's possible until we walk the landscape, and people were shocked that it works." The deeper thesis is that the whole industry is converging on declaring *outcomes* rather than *methods*: Codex ships a `/goal` feature, Anthropic just released an Outcomes API, and OpenProse is an early framework-level articulation of this design philosophy — specify what you want to be true, not how to make it true.
